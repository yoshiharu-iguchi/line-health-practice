# LINE体調報告アプリ（練習用）

## 目的

HTML、CSS、JavaScriptを使って、学生の体調報告と教員の確認作業を学ぶための試作です。
実在する氏名・連絡先・体調情報は入力しません。

## 開き方

`index.html` をブラウザで開くと、練習用の画面を確認できます。

## ファイルの役割

- `index.html`：画面の構造
- `style.css`：画面の見た目
- `app.js`：ボタンなどの動き
- `.gitignore`：Gitに保存しない対象の設定
